dnsmasq-webui

Serveur DNS/DHCP de réseau local avec interface web d'administration. Installation en deux commandes sur Debian / Ubuntu.

1 Ajouter le dépôt

Une seule commande importe la clé de signature et enregistre la source apt :

$ curl -fsSL https://dnsmasqwebui.mawena.cloud/setup.sh | sudo bash
Méthode manuelle (sans script)

Si tu préfères ne pas exécuter un script distant, fais-le à la main :

$ curl -fsSL https://dnsmasqwebui.mawena.cloud/repo/dnsmasq-webui.asc \
    | sudo gpg --dearmor -o /usr/share/keyrings/dnsmasq-webui.gpg \
  && printf 'Types: deb\nURIs: https://dnsmasqwebui.mawena.cloud/repo/\nSuites: ./\nSigned-By: /usr/share/keyrings/dnsmasq-webui.gpg\n' \
    | sudo tee /etc/apt/sources.list.d/dnsmasq-webui.sources

2 Installer

$ sudo apt update && sudo apt install dnsmasq-webui

apt tire et configure toute la pile : dnsmasq devient le résolveur du réseau (avec repli sur les DNS publics), le port 53 est libéré de systemd-resolved, et l'interface web est prête.

Créer le compte administrateur

$ sudo dnsmasq-webui create-admin admin

La commande demande un mot de passe puis crée le compte. Connecte-toi ensuite à l'interface web.

Mettre à jour

$ sudo apt update && sudo apt install --only-upgrade dnsmasq-webui

Commandes utiles

CommandeRôle
dnsmasq-webui create-admin <user>Créer / mettre à jour un compte
dnsmasq-webui statusDiagnostic de santé complet
dnsmasq-webui applyRégénérer les .conf depuis MySQL + recharger
dnsmasq-webui backup [dir]Sauvegarde de la configuration
dnsmasq-webui restore <f>Restauration

Désinstaller

$ sudo apt remove dnsmasq-webui     # garde la base + la config
$ sudo apt purge dnsmasq-webui      # efface tout (base MySQL + /etc/dnsmasq-webui)
Prérequis client : Debian/Ubuntu avec curl ou wget. Le dépôt est signé GPG ; aucune configuration supplémentaire n'est nécessaire.
Dépôt apt : https://dnsmasqwebui.mawena.cloud/repo/  ·  Paquet dnsmasq-webui pour Debian / Ubuntu.
